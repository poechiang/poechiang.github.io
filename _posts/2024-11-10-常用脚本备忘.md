## 常用脚本备忘

## SSH

### 查看本机是否已经生成 了SSH公钥

```bash
# macos
ls ~/.ssh/id_<xxxxx>.pub
```

### 生成新SSH公钥

```bash
# macos
ssh-keygen -t rsa -b 4096 -C "you@email.com"
```

### 打印SSH公钥

```bash
#macos
cat ~/.ssh/id_<xxxxx>.pub
```

### 测试SSH连接

```bash
# macos
ssh -T git@<git_url>
```
